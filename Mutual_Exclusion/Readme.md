# Welcome to Mandatory Hand-in 4 'Mutual exclusion'

**how to run program**

- open a terminal and navigate to the Mutual_Exclusion folder
- From the terminal write: _go run ._
- If successfull instructions will appear in the terminal 
- Follow the instructions 
- Press ctrl + c to quit the program

- Note: the program uses Go version 1.19, check go.mod for further information on versions of packages
